### ⚡ Load Prediction AI System | Jul 2025
🔗 https://github.com/sdShaggy/Load-Prediction-AI-model  

*Python, XGBoost, LightGBM, Optuna, Flask, Selenium*

- Built a **Selenium, BeautifulSoup and Meteostat ingestion pipeline** pulling from 3 external sources (SLDC load data from 4 DISCOMs, weather, public holidays) into one dataset, with scheduled daily scraping and retraining.
- Engineered **14 input features** and trained a **stacked ensemble** (XGBoost, LightGBM, Ridge meta-learner) tuned with Optuna and validated with `TimeSeriesSplit`, reaching **12.3% MAPE** on next-day peak load.
- Shipped a **Flask dashboard** serving next-day predictions with RMSE and error %, refreshing hourly from one serialized model artifact.

### 🖐️ GAN-based Automated Fingerprint Identification System (GAFIS) | Aug 2026
🔗 https://github.com/sdShaggy/GAFIS

*Python, PyTorch, Pix2Pix GAN, YOLOv8, SourceAFIS, OpenCV, Streamlit*

- Engineered an **end-to-end latent fingerprint pipeline** (Pix2Pix enhancement, YOLOv8 minutiae localization, SourceAFIS matching), training Pix2Pix on **5,400 synthetically degraded pairs** from SOCOFing and PolyU noise.
- Improved validation **PSNR from 16.90 to 28.58 dB**, **SSIM from 0.6949 to 0.9661**, and SourceAFIS pass rate from **65.8% to 91.8%**, recovering 24.5 average minutiae per fingerprint.
